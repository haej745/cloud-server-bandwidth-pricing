## 带宽数字别直接比：200M、10M、3M不是一回事

200M峰值、10M固定、3M固定，三个数字放在一张表里比大小没有意义。

阿里云38元轻量的200M是突发峰值，套餐内不限流量，但有评测做过压测：持续大流量下载会被平台限流，CPU是共享算力，长时间满负载会触发算力限流。它适合间歇访问的静态站，不适合视频、下载站、持续高并发。

3M和5M是固定带宽，速度恒定，不会突然掉。换算一下，1M带宽理论下载速度约128KB/s，3M就是约384KB/s，5M约640KB/s。一个没有大图的 WordPress 站，3M够几十人同时在线；首页塞了几张未压缩图片，3M就会明显卡。

雨云国内节点标的10M是固定带宽，比3M快三倍多，这是它604元一年和99元一年之间那五百块差价的实际内容。海外节点更明显：香港2核2G 5M、东京2核2G 8M、洛杉矶2核2G 15M，年付都在320到361元之间，这个价位在大厂体系里通常只能拿到境外最低配。

还有一类容易被忽略的：宿迁BGP（NAT）机型。NAT意味着共享公网IP，靠端口映射对外提供服务，不能像独立IP那样直接占着80和443。它适合面板、测试环境、内网穿透的落地端，不适合正经对外建站。184元一年买到1核1G 10M，图的就是便宜和带宽。

## 买了之后：镜像怎么选，安全怎么配

雨云控制台支持一键预装宝塔面板或1Panel，也有LAMP/LNMP、Docker、WordPress、Halo这类应用镜像。选镜像的逻辑很简单：不想碰命令行就宝塔或1Panel，要跑容器就Docker，建站直接WordPress或Halo。Jenkins、GitLab Runner这类镜像适合做CI/CD，个人站基本用不到。

机器开出来之后，四件事按顺序做：

1. 改SSH端口，禁用root远程登录，改用密钥登录。这三步挡掉绝大部分暴力破解。
2. firewalld只放行80和443，其余端口全关。
3. 静态资源（图片、视频、附件）放对象存储，别堆在系统盘上。
4. 定期打快照，同时清理过期快照。快照本身会产生存储费用，只打不清，账单会慢慢涨。

运行一段时间后看监控：CPU或内存长期在80%以上，说明配置不够，该升档了，硬扛只会让访问越来越慢。
